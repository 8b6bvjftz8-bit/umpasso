UMPASSO — MVP PROTOTYPE
1. Open index.html in a modern browser to try the prototype.
2. For installable PWA behavior, host this folder on HTTPS (e.g. GitHub Pages) and visit the URL on your phone.
3. Android: browser menu > Install app / Add to Home screen.
4. iPhone: Safari > Share > Add to Home Screen.
Included: interactive prompt, time/energy selectors, action suggestions, local history, streak and local-only premium interest button.
Not included: user accounts, cloud sync, real notifications, backend, payment processing, subscription validation or analytics.
Before launch: add privacy policy, terms, data deletion/export, accessibility checks, server-side account and subscription logic, payment integration and security review.
